# App Store Review Notes — PRISM

**Bundle ID:** `com.cortexnode.prism`  
**Version:** 1.0.0 (2026070220)  
**Category:** Social Networking / Productivity  

## What this app does

PRISM is a **complete on-device draft studio** for multi-channel content:

- Write a source signal
- Refract to 10 channel-specific drafts (X, Instagram, LinkedIn, YouTube, etc.)
- Draft queue, approval gate, campaign calendar, audit trail
- Image Studio with local preset gallery, share sheet, proof attach
- **Nothing publishes to live platforms** — operator must approve; publish rail is offline

## Demo flow for reviewer (no login)

1. Home → write signal → **Queue Refraction Preview**
2. **Modules → Draft Queue** — see saved drafts
3. **Modules → Approval Gate** — Approve or Reject
4. **Modules → Platform Outputs** — read channel copy → Share
5. **Studio tab** → Generate Preview → Share / Attach Proof
6. **Activity** + **Audit Trail** — local event log
7. **WORLD · NEXUS · GAMING** — shell preview tabs (not live connectivity)

## What is NOT in this build

- Live OAuth to social platforms
- Live cloud publish (Blotato/API)
- CORTEX brain cloud routing (future update)
- In-app purchase checkout (plans sheet shows honest “App Store setup pending”)

## Approval gate (critical)

No auto-posting. Reviewer will see **Draft Studio · Approval required** throughout. Approve only enables local export/share — not platform publish.
